# 前端当前执行记录

## 2026-11-27 风格 Demo

- 三个 HTML 页面只保留主题差异，共用 `assets/demo.css` 和 `assets/demo.js`，避免样例内容或交互分叉。
- 使用原生 dialog、拖放和响应式 CSS，无外部依赖；任务详情中的象限选择同时提供非拖动操作路径。
- 用户输入通过 DOM `textContent` 渲染，不拼接到 HTML；数据仅存在页面会话中。
- 主题使用 CSS 变量，后续选型后可映射到 React 组件的设计令牌。
- 后续完整原型可复用 dnd-kit、FullCalendar 标准版和 shadcn/ui，但模块任务生成与象限规则仍由项目自身实现。

## 2026-11-27 React 完整原型

- 技术栈正式确定为 React + TypeScript + Vite；目录与运行说明见 `code/frontend/README.md`。
- 三主题使用 CSS 变量，默认 `warm`，主题选择保存在 localStorage；业务数据保持会话内模拟状态。
- 四象限与财务公式放在 `utils` 并由 Vitest 覆盖；页面不得复制这些规则。
- dnd-kit 用于任务拖动，FullCalendar 仅日历页懒加载；后续修改可先从 `docs/05-前端技术与目录结构.md` 定位。
- 浏览器验收覆盖 8 个页面、主要操作、主题持久化及桌面/窄屏布局。
