本项目采用“设计者掌舵、确认后交接员工”的流程。

设计者也是主管，负责项目开头并管理草稿、spec、todo 和 SOP，承担产品边界、调研、原始问答、方法论、风格 Demo、可交互原型和模块审阅；用户确认初版后，主管形成员工 spec，员工一次回访并正式执行。员工的一次 spec 完成后，主管将当时草稿与 spec 拼接归档到 specs，再重置工作模板。

当前初版设计见 `docs/design/01-初版设计.md`，设计原型见 `code/frontend/`。当次大任务 001 位于根目录 `todo.md`，等待用户在主管草稿中审批；员工同时读取 todo 与 spec。工作流程见 `SOP-Skills/001-产品设计与开发流程.md`，大任务发起规则见 `SOP-Skills/004-大任务发起与审批流程.md`。员工公共区负责技术调研、公共测试和联调，前端、后端保留各自技术记录；目录说明见 `docs/初始化说明.md`。
